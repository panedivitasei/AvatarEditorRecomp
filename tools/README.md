# Tools

The GUI apps need Python with PySide6 (`pip install PySide6`). Both are
driven by `avatarextract`. It builds with the recomp and can be used on its own. 

## Dry Cleaner

A GUI app used to import avatar items and avatar awards into the editor.
Accepts marketplace and awards containers or a raw `.bin`.

Award containers carry no game icon, so Dry Cleaner comes with an option to set an icon for each title. 

## Avatar Export

A GUI app used to export the saved avatar to various external filestypes such as `.dae` rigged on the Tower
Unite Workshop rig, `.glb`, `.obj` and `.smd`, with textures and UV maps included.
